# 3dp-desk-organizer
Tired of messy drawers and a messy desk? I designed drawer and desk organizers to help me sort all of my books, papers, pens, pencils etc.

# Drawer organizers
<img width="726" height="471" alt="image" src="https://github.com/user-attachments/assets/1cd2a2de-59ef-418f-bae1-b1357c65aacb" /> </br>
This organizer is based on a 25cm x 43cm grid with many boxes that can be moved around according to your needs and wants.
Each grid square is 5.5x5.5cm and you can comobine multiple boxes in it such as:
- 2x2 box (for post-its and wite outs)
- 2x3 box (for stickers and miscellaneous objects)
- 1x4 box (for holding pens and pencils)

# Desk organizer
<img width="623" height="454" alt="image" src="https://github.com/user-attachments/assets/2c137f92-d767-4d69-b298-e83da0110cd1" /> </br>
This desk arganizer has two drawers, 4 places to put pens and pencils as well as a place to put your books neatly. You can also put post-its in the hanging folders above.

This project was made for Half Life week 2.
